## Default Permission

Allows every kernkraft command

#### This default permission set includes the following:

- `allow-list-dir`
- `allow-create-dir`
- `allow-create-file`
- `allow-rename`
- `allow-start-op`
- `allow-answer-conflict`
- `allow-cancel-op`
- `allow-trash-list`
- `allow-trash-restore`
- `allow-trash-purge`
- `allow-undo`
- `allow-redo`
- `allow-undo-state`
- `allow-watch-dir`
- `allow-unwatch-dir`
- `allow-properties`
- `allow-user-dirs`
- `allow-same-filesystem`
- `allow-text-open`
- `allow-text-save`
- `allow-text-check`
- `allow-thumb-request`
- `allow-thumb-cancel`
- `allow-theme-get`
- `allow-theme-set-prefs`
- `allow-apps-for`
- `allow-app-default`
- `allow-all-apps`
- `allow-launch-app`
- `allow-open-default`
- `allow-set-default-app`
- `allow-open-terminal`
- `allow-mime-of`
- `allow-volumes-list`
- `allow-volumes-problems-take`
- `allow-volume-mount`
- `allow-volume-unmount`
- `allow-volume-eject`
- `allow-search`
- `allow-documents`
